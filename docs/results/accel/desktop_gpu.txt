Notes: nets sum CPU 675 ms -> DirectML 53-101 ms, CUDA 59-64 ms (about 7-12x); the page is then bound by run_photo's
CPU stages (~1.4-1.7 s). GPU stages on save ~150-250 ms per page (final resample, global remap). DirectML net times
are bimodal between runs (e.g. SD-HR 24 vs 57-71 ms), apparently the GPU's clock state: they are lower when the GL
stages keep the GPU busy. CUDA's first run on this driver JIT-compiled ORT's kernels for sm_120 (ORT 1.22.0 has no
native sm_120 code): page finder 55.2 s once, then cached by the driver (C:/Users/User/AppData/Roaming/NVIDIA/ComputeCache,
86 MB); the "cold first page" column was measured with that cache warm. Plan estimate for an NVIDIA desktop page was
~1.2-1.5 s (estimate); measured 1.6 s with both GPU paths on these 5 photos.
