Machine: i5-14400F (10 cores / 16 threads), 32 GB, Windows 11; MSVC Release (/fp:precise), OpenCV 4.11 vc16.
Measured 2026-10-21 12:25-12:30 while other agents' jobs were running on the same machine (no heavy
lock was held by anyone during the run, but the CPU was not idle): treat these as indicative, not a
clean benchmark.

Build:  tools/desktop_check (see the gate commands below), commit d64f88f on accel/b.

        (pipeline_cli PHOTO OUT.jpg net with FS_NETS=1 FS_SHADE_NET=... FS_SHADE_AFTER=1: page finder,
        first UVDoc pass, UVDoc + SyntheticDoc-HR on the re-crop, ShadeNet, all through Inference)
Set:    the 35 photos (34 round-4 photos + the hand-held receipt), one photo per process, one at a time.

"ms" = Inference::last_ms (the ORT Run call alone). "first call" = input preparation + checks + the
session creation (model load, graph optimisation) on the first use of that net in the process; the
app keeps its sessions, so from the second photo on only "ms" (plus input preparation) is paid.
uvdoc's first call is cheap because uv_pass1 already created the UVDoc session.
